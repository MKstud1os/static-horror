# STATIC

A multiplayer first-person horror game for desktop browsers. 1 to 5 players, no weapons. Something inside a 20-room research facility is listening, and it can use anything with power.

## Run it on your computer
1. Install Node.js (the "LTS" version) from https://nodejs.org
2. Open a terminal and go into this folder: `cd path/to/STATIC`
3. Install the libraries (once, needs internet): `npm install`
4. Start the server: `npm start`
5. Open **http://localhost:3000** in Chrome, Edge or Firefox. Keep the terminal open.

To stop the server press Ctrl+C in the terminal (or close the terminal window). The game also needs internet when it loads, because it fetches Three.js from unpkg.com.

**Play with friends on the same Wi-Fi:** they open `http://YOUR-COMPUTER-IP:3000` (on a Mac run `ipconfig getifaddr en0` to find it). Click Play, Create private room, share the 4-letter code, everyone clicks Ready, then the host clicks Start.

## Controls
W A S D move, mouse look, Shift sprint (stamina), Ctrl or C crouch, E interact / read a note / hide in a locker / revive a teammate, F flashlight, **Q EMP pulse**, Esc pause.

## How to win
1. Trace the signal at the terminal in the Security Office.
2. Reset both breakers (Cold Storage and Server Hall). The Signal Chamber gate opens.
3. At the final terminal press **E**. The chamber discharges and everyone is thrown into a long hallway with STATIC behind them. You sprint automatically, so just run: slalom around the server racks, cross live cables only while they are dark (a yellow blink warns you before they fire), and reach the green EXIT. STATIC is fast but slower than you, so it only catches you if you stop or get shocked (Escape ending).
4. Or find all 3 notes plus the trace and press **R** at the terminal (Secret ending).
5. If corruption hits 100% or everyone is down, you get the Failure ending.

## Things to know
- **EMP (Q):** stuns STATIC for a few seconds if it is manifested, in front of you and close. Cooldown is 45s on Easy, 60s on Normal and 90s on Hard.
- **Scares:** now and then something scary happens that cannot hurt you (behind you, in the dark, in a screen, in your ear). Being caught is the only thing that costs you.
- **Difficulty:** Easy, Normal or Hard on the Play screen (the host's choice applies to a room).
- **Settings** (sensitivity, volume, graphics quality, subtitles) are remembered between visits.

## Put it online for free (Render)
You do not need to run it on your own computer. These steps use only websites.
1. Make a free account at github.com. Click New repository, name it `static-horror`, and create it.
2. On the new repository page click "uploading an existing file". Drag in everything from inside the STATIC folder (`client`, `server`, `package.json`, `render.yaml`, `README.md`). Do NOT upload a `node_modules` folder. Click Commit changes.
3. Make a free account at render.com (sign up with GitHub). Click New +, then Web Service, and pick your `static-horror` repository.
4. Set Runtime to Node, Build Command to `npm install`, Start Command to `npm start`, and Instance Type to Free. Click Create Web Service.
5. After a few minutes you get a link like `https://static-horror.onrender.com`. Send that link to friends.

Good to know about the free plan: the first visit after a quiet period takes up to a minute to wake the server; it sleeps after 15 minutes with no traffic (an active game keeps it awake); rooms are kept in memory, so a restart or sleep ends any game in progress. To update the game later, upload the changed files to GitHub again and Render redeploys automatically.

## Where things are
- `server/server.js`: the map, rooms, shared state, objectives, endings, EMP, scares and the monster AI (8 states).
- `client/index.html`: menus, lobby, HUD and styling.
- `client/main.js`: 3D scene, controls, lighting, sound and multiplayer sync.
- Everything (models, textures, sounds) is generated by code, so no asset files are needed.

Edit the map in `server/server.js` (the room grid, door lists and object lists at the top). Monster speed and timers are inside `tick`, and difficulty numbers are in the `DIFF` table.
